# Security Policy

## Supported Versions

While the project is in early development, we will only support the latest version. Once we reach a stable release, we
will maintain support for the last two major versions.

| Version | Supported |
|---------|-----------|
| 2.0.0   | Yes       |
| 1.4.x   | No        |
| 1.3.x   | No        |
| 1.2.x   | No        |
| < 1.2.0 | No        |

## Reporting a Vulnerability

PLEASE **DO NOT OPEN A PUBLIC ISSUE** FOR SECURITY VULNERABILITIES.

Instead, please report it privately to me:

- **Email:** security@ininids.in.rs
- **Telegram:** @ininids

**What you need to include:**

1. Detailed description of the vulnerability, including potential impact and attack vectors.
2. Proof of concept (PoC) or steps to reproduce the issue, if possible.
3. Your environment details (OS, Rust version, etc.).

I will respond as soon as possible and work with you to resolve the issue. Once a fix is ready, I will coordinate with
you on how to disclose it publicly.
