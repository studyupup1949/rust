# Abhedya Chhandas

The **Sanskrit Metering** engine for Abhedya.

This crate is responsible for:

- Mapping numerical values to Sanskrit syllables (Varnamala).
- Enforcing prosodic rules (Laghu/Guru weights).
- Generating "Anushtubh" meter patterns for steganographic output.

Part of the [Abhedyam](https://github.com/ParamTatva-org/abhedyam) project.
