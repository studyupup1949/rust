# acpkit

ACP Kit provides ACP adapters and transport tooling for exposing existing agent runtimes through the
Agent Client Protocol.

Today the production implementation ships in Python:

- Docs: <https://vcoderun.github.io/acpkit/>
- Source: <https://github.com/vcoderun/acpkit>

This crate is intentionally minimal for now and does not yet provide a Rust implementation of the
full ACP Kit surface.
