# Acropolis OS

Acropolis OS is a new OS built by Knott Dynamics.

Acropolis OS is a Linux-based operating system concept built around custom
solutions from Knott Dynamics. It is designed as a full custom stack, combining
the Linux kernel with purpose-built system services, developer tooling, runtime
components, and user-facing workflows.

The goal of Acropolis OS is to provide a cohesive platform where each layer is
selected or designed to work as part of a single integrated environment. From
system initialization and package management to application delivery and device
operations, Acropolis OS presents a focused operating system experience shaped
by Knott Dynamics' engineering direction.

This crate currently seeds the public package identity and documentation for
Acropolis OS.
