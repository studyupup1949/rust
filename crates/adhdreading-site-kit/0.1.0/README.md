# ADHD Reading Site Kit

Small URL helpers for [ADHD Reading](https://adhdreading.org), a Chrome extension for focused reading with Bionic Reading, semantic highlighting, focus mode, and typography controls.

## Links

- Website: <https://adhdreading.org>
- Features: <https://adhdreading.org/features>
- Download: <https://adhdreading.org/download>
- Blog: <https://adhdreading.org/blog>
- Pricing: <https://adhdreading.org/pricing>
- FAQ: <https://adhdreading.org/faq>
- Chrome Web Store: <https://chromewebstore.google.com/detail/adhd-reading/dgihjimekmhphkbnnnomcbemhinmhmeg>

## Purpose

This repository keeps tiny, installable helpers for package registry metadata and examples. Each package exposes the same small set of stable ADHD Reading links.
