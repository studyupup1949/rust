# ADIF Surgeon

A tool for doctoring your ADIF records.

**NOTE**: This is alpha level software. Make backups of your important contest logs, etc.

## Usage

adifsurgeon \
 --infile <input.adi> \
 --outfile <output.adi> \
 --drop <record>=<value> \
 --keep <record>=<value> \
 --insert <record>=<value> \
 --replace <record>=<value> \
 --delete <record> \
 --start <timestamp> \
 --end <timestamp>
