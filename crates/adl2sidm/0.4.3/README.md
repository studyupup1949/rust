# ⚠️ adl2sidm is deprecated — renamed to `adl2rsdm`

`adl2sidm` has been renamed to [`adl2rsdm`](https://crates.io/crates/adl2rsdm).
This crate re-exports the `adl2rsdm` library and is no longer maintained; the
`adl2sidm` binary now only prints this notice.

Install and use the new tool:

```text
cargo install adl2rsdm
```
